# JMeter AOD Plugin

Кастомный плагин для Apache JMeter, который влючает в себя следющие ф-ции:
 - __timeTZ: возвращает текущую дату и время в указанном часовом поясе
 - __timeShiftTZ: возвращает дату откосительно указанного часового пояса в различных форматах с добавлением указанного количества секунд/минут/часов/дней 

## 📌 Возможности

- Поддержка любого часового пояса (например, `UTC`, `Europe/Moscow`, `+03:00`)
- Гибкий формат вывода даты/времени
- Сохранение результата в переменную JMeter

## 🚀 Установка

1. Скомпилируйте проект в JAR-файл
2. Поместите полученный JAR-файл в папку `lib/ext` вашей установки JMeter
3. Перезапустите JMeter
