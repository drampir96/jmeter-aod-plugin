# JMeter AOD Plugin

Кастомный плагин для Apache JMeter, который включает в себя следующие ф-ции:
 - `__timeTZ`: возвращает текущую дату и время в указанном часовом поясе

## 📌 Описание

- Функция `__timeTZ` расширяет возможности стандартной функции [`__time`](https://jmeter.apache.org/usermanual/functions.html#__time:~:text=%5E-,__time,-%C2%B6) из Apache JMeter.
- Ключевое отличие от стандартной — возможность указать временную зону (например, `UTC`, `GMT+3`, `Europe/Moscow`, `America/New_York`), что позволяет получать корректное время для любого региона без изменения настроек операционной системы.

## Параметры

| Параметр | Описание | Обязательный |
|----------|----------|--------------|
| `формат` | Формат даты/времени (совместим с `SimpleDateFormat`/`DateTimeFormatter`) или `/` + делитель для миллисекунд | Нет |
| `часовой_пояс` | Идентификатор часового пояса (например, `UTC`, `GMT+3`, `Europe/Moscow`, `America/Los_Angeles`) | Нет |
| `имя_переменной` | Имя переменной, в которую будет сохранено значение | Нет |

## Примеры использования
- ${__timeTZ()} → 1734567890123 (Возвращает текущее кол-во миллисекунд с 1970-01-01)
- ${__timeTZ(yyyy-MM-dd HH:mm:ss, UTC)} → 2025-12-18 15:30:00 (Простой формат UTC)
- ${__timeTZ(dd.MM.yyyy HH:mm:ss, Europe/Moscow, myTime)} → 18.12.2025 18:30:00 (Формат с московским временем + сохранение в переменную)
- ${__timeTZ(yyyy-MM-dd HH:mm:ss, GMT+4)} → 2025-12-18 19:30:00 (Использование GMT+3)

## 🚀 Установка

1. Скомпилируйте проект в JAR-файл
2. Поместите полученный JAR-файл в папку `lib/ext` вашей установки JMeter
3. Перезапустите JMeter
